# 命令解释

一条 zsh 命令执行完、提示符回来后，按 **⇧⌘E**，或选菜单栏的「Agent → 命令解释」。解释针对当前分屏刚执行的命令，直接出现在终端正文中。先在[模型服务](./service)中保存配置。

使用 v0.2.15 发行版时，可[从源码构建](../guide/start#从源码运行)体验成功命令的解释。

## 看懂成功的命令

例如，运行下面的命令，再按 **⇧⌘E**。

```sh
git log -1 --oneline
```

解释会说明 `-1` 限制为最近一次提交，`--oneline` 将提交缩写和标题放在同一行。成功的命令保持普通的终端排版，也可以解释没有输出的命令。

## 排查失败的命令

命令返回错误时，错误输出旁会出现「命令解释」按钮。例如，将 `git status` 输入为 `gti status` 后，可以直接点报错旁的按钮。

模型会结合命令、退出码和末尾输出说明原因。有可靠的修正时，建议命令会填入当前提示符，可先编辑，再按回车执行。如果已经输入了其他文字，草稿会保留，建议单独显示。

## 发给模型的内容

只有主动请求解释时才联系模型。请求包含 shell 名称、工作目录、命令、退出码，以及末尾最多 24 行、约 3,000 个字符的输出。开始下一条命令后，上一条请求的迟到回复会被丢弃。

在「设置 → 快捷键」可以修改组合键，在「AI 服务 → 终端功能」可以关闭命令解释。
