# 在终端运行 Agent

内置 Agent 使用已配置的[模型服务](./service)。按 **⌘J** 后，当前目录旁会出现 `Agent >`。之前的命令和输出仍在原处。

## 提交任务与确认命令

例如，输入「列出当前目录下最近修改的五个文件」，按回车提交。Agent 提出的命令会显示在当前分屏的执行框中。先看命令，再按 **Enter** 同意执行，或按 **Ctrl+C** 取消。

程序使用当前 shell、目录和输入输出。每条命令的实际结果会留在执行框里，Agent 据此决定下一步。任务结束后再次出现 `Agent >`，这时可以继续输入。

按 **↑**、**↓** 翻阅当前会话最近 32 条 Agent 任务。按 **⌘J** 或输入 `/exit` 返回 shell，会恢复切换前的输入草稿。

## 使用本机工具

在「Agent → 在当前终端运行」中选择已安装的 Codex、Claude Code、Antigravity、Qoder CN 或 omp。工具沿用自己的账号、模型和权限。支持的工具完成一轮任务时，铃铛会显示摘要或完成状态。

## 显示与请求范围

「设置 → AI 服务 → Agent 显示」可以调整当前目录和提示符颜色、执行框内边距，并选择是否流式显示文字。内置 Agent 单个任务最多请求 8 步，读取单个项目文件最多 6 KiB。每步送给模型的终端输出取末尾最多 24 行，终端中仍保留完整输出。
