# 连接模型服务

命令解释和内置 Agent 共用一组模型配置。按 **⌘,** 打开「设置 → AI 服务」，填写以下四项。

| 字段 | 填写内容 |
| --- | --- |
| 服务地址 | 服务商的基础地址或完整请求路径，例如 `https://api.openai.com/v1` |
| API Key | 该服务商签发的密钥 |
| API 格式 | 按服务商支持的接口选择 Chat Completions、Responses 或 Anthropic Messages |
| 模型名称 | 服务商提供的模型 ID |

兼容服务需要同时匹配地址、格式和模型名。本机服务可以使用 `http://localhost:端口/v1`。

## 测试并保存

点「测试连接」会向当前填写的模型发送一条短消息，服务商可能计费。测试通过后点「保存」。配置加密写入当前用户的 `~/Library/Application Support/YaaTerm/Credentials/`，解密密钥也保存在本机。

如遇认证错误，检查地址与密钥是否属于同一个服务。提示模型不存在时，核对模型 ID 及该密钥的访问权限。

## 选择要启用的功能

「AI 服务 → 终端功能」可以分别开关命令解释、内置 Agent 和本机 Agent。全部关闭后，工具栏会收起入口。要使用自己已安装的 Codex 或 Claude Code，选择本机 Agent 即可，该工具沿用自己的登录和权限。
