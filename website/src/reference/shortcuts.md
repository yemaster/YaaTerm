# 快捷键

以下为默认组合键。⌘ 是 Command，⌥ 是 Option，⇧ 是 Shift。

## 窗口和会话

| 操作 | 快捷键 |
| --- | --- |
| 新建窗口 / 标签页 | ⌘N / ⌘T |
| 上一个 / 下一个标签页 | ⇧⌘[ / ⇧⌘] |
| 左右 / 上下分屏 | ⌘D / ⇧⌘D |
| 上一个 / 下一个分屏 | ⌥⌘[ / ⌥⌘] |
| 关闭当前分屏 | ⌘W |
| 打开设置 | ⌘, |

## 阅读与输入

| 操作 | 快捷键 |
| --- | --- |
| 搜索当前分屏 | ⌘F 或 Ctrl+F |
| 搜索下一处 / 上一处 | Return / ⇧Return |
| 关闭搜索 | Esc |
| 复制 / 粘贴 | ⌘C / ⌘V |
| 放大 / 缩小 / 还原字号 | ⌘= / ⌘− / ⌘0 |
| 解释刚执行的命令 | ⇧⌘E |
| 切换 Agent 输入 | ⌘J |
| 确认 Agent 命令 / 取消 | Enter / Ctrl+C |

## 自定义

打开「设置 → 快捷键」，点按要改的操作，再按新组合。录制时按 Esc 取消，按删除键清除。要恢复某一项，右键该项并选择恢复默认值。
