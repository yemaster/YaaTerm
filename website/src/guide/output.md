# 阅读与搜索输出

在 zsh 中运行 `ls -lh`，文件名、大小、修改时间和权限会按列对齐。每份列表右上角都可以切换「表格」和「原始数据」。拖选后按 **⌘C** 可直接复制，跨列时用制表符分隔。

## 哪些命令可以显示表格

| 工具 | 支持的标准输出 |
| --- | --- |
| macOS | `ls -l`、`df -h`、`ps`、`ps aux`、`ps -ef`、`launchctl list` |
| Git 和 Python | `git remote -v`、`git worktree list`、`pip list` |
| Docker | 容器、镜像、网络和卷列表，如 `docker ps` |
| Kubernetes | `kubectl get` 的 pods、services、deployments 和 namespaces 默认列 |

管道、重定向和自定义列沿用命令的原始输出。在「设置 → 终端 → 命令输出」可以关闭表格。

## 查看源文件

直接运行 `cat main.swift` 可查看带行号的代码，复制和搜索使用正文。`nl`、`cat -n` 和 `cat -b` 沿用命令自带的编号。代码和普通文本使用同一套字体，字号和字重随外观设置调整。「代码行号与高亮」可以单独关闭。

## 搜索与链接

按 **⌘F** 或 **Ctrl+F** 输入关键词。**Return** 跳到下一处，**⇧Return** 跳到上一处，**Esc** 返回终端。搜索忽略大小写，支持中文和跨自动折行匹配。表格按原始文本查找，Vim 等全屏程序则查找当前屏幕。

按住 **⌘** 移动指针，出现手形时即可点按。网址在浏览器打开，本地路径在 Finder 中定位。支持 HTTP(S)、本机 `file://` 和 OSC 8 超链接。网页和文件入口可以在「设置 → 终端 → ⌘ 点按」分别关闭。
