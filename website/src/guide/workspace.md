# 标签页与分屏

一个标签页可以容纳多个分屏。每个分屏都是独立的 shell，有自己的工作目录、前台进程和回滚记录。

## 并排运行命令

按 **⌘D** 左右分屏，按 **⇧⌘D** 上下分屏。点正文切换输入位置，拖动分隔线调整大小。还可以在已有分屏里继续分割。

例如，左边运行开发服务器，右边运行测试。要停服务器，先点左边，再按 **Ctrl+C**。**⌘W** 关闭当前分屏；点标签上的关闭按钮会关闭整页。

## 整理标签

- **新建与排序**　按 **⌘T** 或点标签旁的加号。拖动标签调整顺序。
- **移动到窗口**　把标签拖出标签栏即可独立成窗。拖进另一扇 YaaTerm 窗口的标签栏可指定位置，拖到正文会放在末尾。松手前按 Esc 取消。
- **分组**　右键标签新建分组，把其他标签拖到组名上。点组名收起或展开，右键组名可以改名、换色和取消分组。

移动标签时，分屏布局、正在运行的程序和已有输出都会保留。

## 任务完成提醒

在默认 zsh 中，离开标签后，普通外部命令退出时会收到提醒。支持的本机 Agent 完成一轮任务时，即使正在看该分屏也会提醒。点横幅或右上角铃铛里的记录即可返回任务所在位置，已收起的分组会自动展开。

「设置 → 通用 → 提醒」可以筛选普通命令，只提醒运行满 10 秒的命令，或仅保留 Agent 提醒。铃铛保留最近 32 条记录。
