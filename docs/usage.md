# YaaTerm 使用指南

## 标签页和分屏

按 ⌘T 新建标签页。左右分屏用 ⌘D，上下分屏用 ⇧⌘D。每个分屏有独立的登录 shell，拖动分隔线可调整大小。⌘W 关闭当前分屏，点标签上的关闭按钮会关闭整页。

拖动标签可排序、拖出成独立窗口，或放进另一扇窗口。拖到标签栏可选插入位置，拖到正文会追加到末尾，Esc 取消。移动时会保留原来的 shell、输出和分屏。右键标签可新建分组，或将标签拖到已有组名上。点组名收起、展开，右键可改名或换色。

齿轮固定在标签栏右侧。点齿轮或按 ⌘, 进入设置，点原标签即可回到会话。其他默认快捷键如下。

| 操作 | 快捷键 |
| --- | --- |
| 新建窗口 | ⌘N |
| 切换标签页 | ⇧⌘[ 或 ⇧⌘] |
| 切换分屏 | ⌥⌘[ 或 ⌥⌘] |
| 搜索当前分屏 | ⌘F 或 Ctrl+F |
| 下一个 / 上一个匹配 | Return / ⇧Return |
| 返回终端输入 | Esc |
| 放大 / 缩小 / 还原字号 | ⌘= / ⌘− / ⌘0 |

在「设置 → 快捷键」中点按某项，再按新组合即可改键。录制时按 Esc 取消，按删除键清除，右键可恢复单项默认值。输入 `exit` 或在空提示符按 Ctrl+D，默认会关闭对应分屏。

## 阅读命令输出

默认 zsh 可以把以下命令的标准列表显示成表格。每份输出右上角都能单独切换「表格」和「原始数据」。拖选表格后按 ⌘C，列之间会用制表符分隔。

| 来源 | 支持的输出 |
| --- | --- |
| macOS | `ls -l`、`df -h`、`ps`、`ps aux`、`ps -ef`、`launchctl list` |
| Git、Python | `git remote -v`、`git worktree list`、`pip list` |
| Docker | 容器、镜像、网络和卷的标准列表 |
| kubectl | `get pods`、`services`、`deployments`、`namespaces` 的默认列 |

直接运行 `cat` 或 `nl` 可显示行号和代码高亮。`cat -n`、`cat -b` 和 `nl` 沿用命令自身的编号。管道、重定向和自定义列表格式保留普通输出。「设置 → 终端 → 命令输出」可分别关闭表格和代码显示。

按住 ⌘ 移到网址或本地路径上，手形指针表示可以点按。网址在浏览器打开，文件在 Finder 中定位。支持 HTTP(S)、本机 `file://` 和 OSC 8 超链接。网页与文件入口可分别在「终端 → ⌘ 点按」中关闭。

搜索支持中文、忽略大小写和跨自动折行匹配，表格按原始文字查找。普通屏幕可搜索整个会话的回滚，Vim 等程序使用备用屏幕时只搜索当前屏幕。Vim 开启鼠标模式后支持滚轮和拖动，按住 Shift 可以选择终端文字。

## AI 和提醒

在「设置 → AI 服务」填写服务地址、模型名、API 格式与密钥。支持 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages。基础地址和完整接口路径都可使用，本机服务可填 `http://localhost:端口/v1`。「测试连接」会向模型发送一条短消息，服务商可能计费。保存后，密文和本机解密密钥位于当前用户的 `~/Library/Application Support/YaaTerm/Credentials/`。

- **解释错误**　命令失败后点报错旁的「解释错误」或按 ⇧⌘E。模型会收到该命令、退出码和末尾输出。原因显示在原处，建议命令可编辑后执行。提示符里已有草稿时会保留草稿。
- **内置 Agent**　按 ⌘J，在当前目录旁的 `Agent >` 输入任务。每条建议命令按 Enter 确认，按 Ctrl+C 取消。程序直接使用当前分屏的输入和输出。↑、↓ 翻阅本会话最近 32 条任务，⌘J 或 `/exit` 切回 shell 并恢复草稿。「AI 服务 → Agent 显示」可调整目录色、提示符色、内边距与流式显示。
- **本机 Agent**　在 Agent 菜单中选择已安装的 Codex、Claude Code、Antigravity、Qoder CN 或 omp，使用工具自己的登录和权限。

内置 Agent 单次任务最多请求 8 步。单个文件最多读取 6 KiB，每步发给模型的命令输出取末尾 24 行，最多约 3,000 个字符。完整输出可以在终端回看。「AI 服务 → 终端功能」可逐项关闭 AI 功能，全部关闭会移除工具栏入口。

默认 zsh 中，离开标签页后，普通外部命令退出时会提醒。本机 Agent 完成一轮任务时，当前标签也会收到提醒。支持的工具会附本轮摘要，点提醒即可回到对应分屏。「通用 → 提醒」可选择仅提醒 Agent、仅提醒耗时至少 10 秒的普通命令和 Agent，或提醒全部。铃铛保留最近 32 条记录。

## 外观、回滚与休眠

- **主题和字体**　在「外观 → 主题」可为系统浅色和深色分别选择配色。内置 Catppuccin、One Half、Solarized、GitHub、VS 和 Tomorrow。默认字体为 JetBrains Mono Light，也可以选择已安装的等宽字体，调整字号和 100 到 900 的字重。终端、代码和表格共用字体。
- **背景**　背景图片、透明度和毛玻璃可在「外观 → 背景」调整，macOS 26 起可选液态玻璃。标签栏和终端共用背景，系统启用「降低透明度」时会停用材质。
- **回滚**　在「性能 → 回滚记录」可选 500、1,500 或 3,000 行内存缓存。更早的记录压缩到会话临时文件，按需读取，会话关闭后释放。选择「关闭」会清空现有回滚，并停止记录后续历史。
- **休眠**　「性能 → 休眠闲置标签页」默认关闭。开启后，后台标签连续 15 分钟没有输出，且各分屏均处于空闲 shell 或已结束时，会压缩网格和回滚缓存。切回标签或收到输出会唤醒，后台作业继续运行。

## Shell 与协议

zsh 首个提示符会加载随包附带的命令高亮。已有的 zsh-syntax-highlighting 或 fast-syntax-highlighting 优先。默认输入超过 512 个字符时跳过高亮计算，可在自己的 `.zshrc` 中设置 `ZSH_HIGHLIGHT_MAXLENGTH`。其他 shell 使用各自的行编辑器。

支持 Unicode Emoji 17.0 合字、DEC 线框字符、可设置的制表位、真彩色、备用屏幕及鼠标报告。组合 emoji 占两列，复制与搜索保留完整序列。SIXEL 图形和部分 xterm 扩展尚未实现。[Unicode Emoji](https://www.unicode.org/reports/tr51/) · [XTerm 控制序列](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html)

## 版本与反馈

「设置 → 关于」提供本版更新日志、检查更新和反馈入口。默认每天检查，已下载的更新会在退出时安装。自动检查和安装均可关闭。[版本记录](https://github.com/yemaster/YaaTerm/releases) · [问题反馈](https://github.com/yemaster/YaaTerm/issues)
